# Cron

[Cron entries](../../cron/index.md) run a bash script on your instance on a
schedule. The API lists, gets, creates, and updates them. The following
endpoints are supported:

- `GET` [List cron entries](list-cron-entries.md)
- `GET` [Get a cron entry](get-cron-entry.md)
- `POST` [Create a cron entry](create-cron-entry.md)
- `PATCH` [Update a cron entry](update-cron-entry.md)

Delete a cron entry from the dashboard, under **Cron** on your instance.
